Cómo apuntar un subdominio a tu VPS

Actualizado el 11 de noviembre de 2026, por el equipo de Jitterx Panel Cloud

Un subdominio es una dirección fácil de recordar, como mi-servidor seguido de nuestro dominio, que apunta a la IP pública de tu servidor. En Jitterx Panel Cloud puedes crear uno gratis en segundos y usarlo, por ejemplo, como origen de tu CDN.

Qué es un registro A

El sistema DNS traduce nombres en direcciones IP. Un registro A asocia un nombre con una dirección IPv4. Cuando alguien escribe tu subdominio, el DNS responde con la IP de tu servidor y la conexión llega ahí. Nuestros subdominios usan el modo solo DNS: no pasan por ningún proxy, apuntan directamente a tu IP.

Paso a paso

  1. Entra a la web y abre la sección Dominio.
  2. Escribe el nombre que quieres: entre 2 y 32 caracteres, con letras minúsculas, números y guiones.
  3. Escribe la IPv4 pública de tu servidor. La vista previa te muestra cómo quedará: nombre.dominio → IP.
  4. Pulsa Crear registro A. En menos de un minuto el subdominio ya resuelve.

Condiciones

  • Es gratis y dura 7 días; después se elimina automáticamente.
  • Puedes tener 1 registro activo a la vez.
  • Solo se admiten IPv4 públicas.

Usarlo como origen de tu CDN

Al contratar tu CDN puedes escribir este subdominio en el campo Origen. Ten en cuenta que dura 7 días: si vence, el CDN ya no encontrará tu servidor. Para un uso continuado es más práctico usar directamente la IP pública o un dominio propio permanente. Si cambias el origen más adelante, hazlo con Cambiar origen, sin costo.

Cómo comprobar que funciona

Desde un ordenador puedes ejecutar nslookup nombre.dominio o ping nombre.dominio: la respuesta debe mostrar la IP de tu servidor. También puedes usar cualquier comprobador de DNS en línea.

Uso responsable. Los subdominios son para tus propios servidores. No se permite usarlos para phishing, suplantación ni actividades ilegales.
