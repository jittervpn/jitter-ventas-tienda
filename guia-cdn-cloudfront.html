Cómo contratar y usar tu CDN CloudFront

Actualizado el 11 de noviembre de 2026, por el equipo de Jitterx Panel Cloud

El CDN CloudFront de Jitterx Panel Cloud te da un punto de conexión propio dentro de la red de CloudFront que reenvía el tráfico hacia tu servidor. En lugar de conectarte directamente a la IP de tu VPS, tu app se conecta a un dominio de CloudFront, y CloudFront entrega la conexión a tu servidor. Esta guía explica qué necesitas, cómo contratarlo y cómo mantenerlo activo.

Cómo funciona

Cada servicio CDN tiene tres datos: un host CDN (un dominio que termina en cloudfront.net), una ruta propia (por ejemplo /c1a2b3cmiruta) y un origen, que es el dominio o la IP de tu servidor. Cuando tu app abre una conexión WebSocket al host CDN con tu ruta, CloudFront la reenvía al origen por el puerto 80. La ruta lleva un prefijo único de tu cuenta, así nadie más puede usar la tuya.

Qué necesitas antes de contratarlo

  • Un servidor propio (VPS) con un servicio que acepte conexiones WebSocket en el puerto 80, por ejemplo un túnel SSH sobre WebSocket.
  • El origen: la IPv4 pública del servidor o un dominio que ya apunte a ella. Si no tienes dominio, puedes crear uno gratis siguiendo la guía de cómo apuntar un subdominio a tu VPS.
  • Una cuenta en la web: entras con tu correo y un código de 6 dígitos, sin contraseñas.

Paso a paso para contratarlo

  1. Entra a la web, inicia sesión y abre la sección CDN del menú.
  2. Elige cómo pagar: Tarjeta, Mercado Pago o PayPal.
  3. En Origen, escribe el dominio o la IP pública de tu servidor.
  4. En Nombre de tu ruta, elige entre 2 y 20 letras minúsculas o números, sin guiones ni espacios. Delante se añade solo el prefijo de tu cuenta.
  5. Pulsa el botón de pagar. Cada servicio cuesta $17.000 y dura 30 días.
  6. Cuando el pago se aprueba, el servicio se crea solo. En unos segundos aparece en Mis servicios CDN con el estado Activo, el host CDN y el payload listo para copiar.

Antes de cobrarte, la web revisa que el origen y la ruta sean válidos. Si después del pago el servicio no se pudiera crear por un dato inválido, el dinero se devuelve automáticamente.

Copiar los datos a tu app

En la tarjeta de tu servicio tienes el host CDN, el puerto 80, la ruta y el payload CloudFront, cada uno con su botón de copiar. Si el proveedor del CDN lo informa, también verás el tráfico del servicio. El payload tiene esta forma:

GET /tu-ruta HTTP/1.1[crlf]Host: tu-host.cloudfront.net[lf]Connection: Upgrade[lf]Upgrade: websocket[crlf][crlf]

Cómo cargarlo en la app está explicado en la guía de configuración de HTTP Custom con tu CDN.

Renovar y cambiar el origen

  • Renovar: en la tarjeta de tu servicio pulsa Renovar, elige cómo pagar y paga de nuevo. Se suman 30 días y conservas el mismo host, ruta y payload, así que no tienes que tocar la app.
  • Cambiar origen: si cambias de servidor, pulsa Cambiar origen, escribe el nuevo dominio o IP y guarda. No tiene costo.
  • La web te avisa cuando a un servicio le quedan menos de 3 días.

Problemas frecuentes

«El dominio de origen no resuelve»

El dominio que escribiste todavía no apunta a ninguna IP. Revisa su registro A o usa directamente la IP pública del servidor.

El servicio está activo pero la app no conecta

Comprueba que tu servidor acepte WebSocket en el puerto 80 y que el firewall del proveedor tenga ese puerto abierto. Revisa también que el payload esté completo, incluida la línea final.

«Esa ruta ya está en uso»

Ya tienes un servicio con ese nombre. Elige otro nombre de ruta.

Uso responsable. El CDN es para conectarte a tus propios servicios. Está prohibido usarlo para spam, ataques o cualquier actividad ilegal; los servicios que lo incumplan se suspenden sin aviso.
